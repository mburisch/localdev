## bun

GitHub: https://github.com/oven-sh/bun

## Description

`bun` is an all-in-one JavaScript & TypeScript runtime, bundler, test runner, and package manager. Drop-in replacement for Node.js with native TypeScript support.

## Examples

```bash
# Run a script
bun run index.ts

# Install dependencies
bun install

# Add a dependency
bun add express

# Run tests
bun test

# Bundle for production
bun build ./index.ts --outdir ./dist
```
