## ruff

GitHub: https://github.com/astral-sh/ruff

## Description

`ruff` is an extremely fast Python linter and formatter written in Rust. Drop-in replacement for Flake8, isort, and Black.

## Examples

```bash
# Lint current directory
ruff check .

# Auto-fix lint issues
ruff check --fix .

# Format code
ruff format .
```
