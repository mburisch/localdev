## uv

GitHub: https://github.com/astral-sh/uv

## Description

`uv` is an extremely fast Python package and project manager written in Rust. Replaces pip, pip-tools, virtualenv, and more.

## Examples

```bash
# Create a new project
uv init myproject

# Add a dependency
uv add requests

# Run a script
uv run main.py

# Sync dependencies
uv sync

# Install a CLI tool globally
uv tool install ruff
```
