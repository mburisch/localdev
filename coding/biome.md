## biome

GitHub: https://github.com/biomejs/biome

## Description

`biome` is a fast formatter, linter, and analyzer for JavaScript, TypeScript, JSON, CSS, and more. Drop-in replacement for ESLint and Prettier.

## Examples

```bash
# Format files
biome format .

# Lint files
biome lint .

# Run both format and lint
biome check .

# Auto-fix issues
biome check --fix .
```
