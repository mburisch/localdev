## yazi

GitHub: https://github.com/sxyazi/yazi
Homepage: https://yazi-rs.github.io

## Description

`yazi` is a terminal file manager with async I/O, built-in file previews (images, PDFs, code with syntax highlighting), and Vim-like keybindings. Highly customizable via Lua plugins.

## Config files
* ~/.config/yazi/yazi.toml
* ~/.config/yazi/keymap.toml
* ~/.config/yazi/init.lua
