## jless

GitHub: https://github.com/PaulJuliusMartinez/jless
Homepage: https://jless.io

## Description

`jless` is an interactive terminal JSON and YAML viewer with collapsible nodes, search, and vim-style navigation.

## Examples

```bash
# View a JSON file interactively
jless data.json

# Read from stdin
curl -s https://api.example.com/data | jless
```
