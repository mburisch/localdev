## lazydocker

GitHub: https://github.com/jesseduffield/lazydocker

## Description

`lazydocker` is a terminal UI for Docker that lets you manage containers, images, volumes, and networks. View logs, inspect resource usage, and restart services all from a single dashboard.

## Examples

```bash
# Launch lazydocker
lazydocker

# Use a custom config directory
LAZYDOCKER_CONFIG_DIR=~/.config/lazydocker lazydocker
```
